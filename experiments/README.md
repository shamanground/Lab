## What was found

- EXP-01, in `../exp01_interaction_geometry/`. Locked.
- EXP-02, in `../exp02_axis_compression/`. Locked. One constraint, five claims, one regime.
- [EXP-0001](EXP-0001-contradiction-edges/conclusion.md). Last note wins loses the disagreement.
- [EXP-0002](EXP-0002-paraphrase-poles/conclusion.md). Raw text invents fights. Negation still fools the cleaner.
- [EXP-0003](EXP-0003-resolution-rules/conclusion.md). A correction and a disagreement are different operations.
- [EXP-0004](EXP-0004-subject-position-gate/conclusion.md). Milestone 25 needs a subject and a position that frozen milestone 19 does not carry. Of four options, only keyed contest survived: same subject, same proposition, same horizon, same goals, both positions kept, no winner. A signal with no subject is rejected.
